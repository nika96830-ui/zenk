## Launch blockers

1. **Deployed functions differ from Git.** Hosted process-meeting v14 uses handler.ts and never calls reserve_meeting_usage. Thus the hosted processing path lacks the Git version's quota reservation. Hosted export-tasks v12 accepts supplied task arrays and lacks the Git CSV formula protections. Do not overwrite blindly: reconcile the hosted owner-bound handler/CORS/error sanitization with the checked-in quota/security changes, test, then explicitly deploy the reviewed result.
2. **Database migration drift.** Hosted migration history ends at remove_stripe; task_meeting_ownership and explicit_api_grants are absent. The owner-checking task policy exists, but the enforce_task_meeting_owner trigger does not. anon and authenticated still have broad table privileges including TRUNCATE, REFERENCES and TRIGGER. RLS does not replace least-privilege grants. Review/apply the missing hardening migrations only through a controlled deployment after backup; do not reapply the entire migration history because hosted timestamps differ.
3. **Playback and task editing are incomplete product features.** The UI has no recording playback control. Task completion can be toggled; task titles/assignees/dates cannot be edited. Exports download files; the Notion/Trello labels do not mean connected integrations.
4. **Live AI and device acceptance remain outstanding.** No billable Whisper/GPT request, provider billing/quota check, real-user persistence test, physical microphone or physical iPhone Safari test was performed. The browser codec test uses an oscillator, not speech or a microphone. Real M4A from iPhone Voice Memos still needs an acceptance test.

## Fixes in this branch

- Accept known M4A MIME aliases and infer supported extensions only for files with missing/generic MIME. Normalize the uploaded Blob itself to audio/mp4 (Supabase multipart uploads otherwise keep the original File MIME). Reject unknown types and files above 25 MiB before upload.
- Parse actual FunctionsHttpError response bodies for safe localized quota/billing/config errors. Invalid JSON and unknown provider details produce a generic error.
- Show a localized export failure and allow retry; successful retry clears the error.
